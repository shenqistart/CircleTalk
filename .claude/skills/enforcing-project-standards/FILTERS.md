# 高信噪比过滤规则

## 应报告（高信号）

| 类别 | 置信度 | 示例 |
|------|--------|------|
| 架构违规 | 95-100 | API 直接调用 Repository |
| 类型错误 | 95-100 | pyright/tsc 报错 |
| 安全漏洞 | 95-100 | SQL 注入、未校验输入 |
| 明确 Bug | 90-100 | 空指针、未处理异常 |
| 命名违规 | 85-95 | 不符合项目命名规范 |
| 设计问题 | 80-89 | 违反 SOLID 原则 |
| 风格问题 | 70-79 | 可读性较差 |

## 不应报告（噪音）

| 类别 | 原因 |
|------|------|
| 个人风格偏好 | 非规范要求 |
| 假设性问题 | "如果将来..." |
| 已有代码问题 | 非本次变更引入 |
| 微观优化 | 无实际性能影响 |
| 文档缺失 | 除非规范要求 |

## 置信度标准

- **95-100**：P0，必须修复
- **90-94**：P0，必须修复
- **80-89**：P1，应修复
- **70-79**：P1，可选修复
- **<70**：不报告
